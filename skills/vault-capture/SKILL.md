# Vault Capture

Write ordinary files beneath
`/Users/aman-mac-work/Documents/PERSONAL/Projects/obsidian-vaults/Second Brain`.

## Workflow

1. Reject credentials and employer/client-confidential material. Ask for a
   sanitized version instead.
2. Choose the narrowest destination:
   - unresolved capture → `00 Inbox`
   - active outcome → `10 Projects`
   - responsibility → `20 Areas`
   - durable concept → `30 Knowledge`
   - source record → `60 Sources`
3. Start from the closest file in `90 Meta/Templates`.
4. Set `type`, `status`, ISO `created`/`updated`, `sensitivity`, `related`, and
   minimal tags. Allowed sensitivity values are `personal`, `public`, and
   `sanitized`.
5. Preserve the user's wording, links, dates, identifiers, and uncertainty.
6. Add wikilinks to known related notes; do not invent relationships.
7. Leave one explicit next action when the capture is actionable.

Use `[[wikilinks]]` only for vault notes and standard Markdown links for URLs.
Do not create MDX or HTML for a normal capture.
