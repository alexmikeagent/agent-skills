What happens when you ask

The path changes. The evidence contract does not.

Small, style-led change

Add or adjust an Assign, If, argument, or narrative log in a mature workflow.

  1. Inspect the project and one sibling anchor.
  2. Edit one coherent XAML slice.
  3. Run changed-scope L1.
  4. Run L2 only when compile proof is required.

Contract-led decomposition

Split a large rule workflow without changing transaction disposition.

  1. Freeze outputs, statuses, reasons, exceptions, and precedence.
  2. Add and register characterization and replacement tests first.
  3. Split by business responsibility; audit each leaf.
  4. Pass L1 with registration enforcement, L2, and L3.
  5. Remove superseded tests, then rerun all three gates.

Evidence before repair

Find the failing contract or serialization boundary without assuming authorization to edit.

  1. Inspect, then run a baseline full or scoped audit.
  2. Stop on malformed XAML or an empty-scope finding.
  3. Locate the first failing gate and stable finding code.
  4. Explain the root cause and smallest safe fix.
  5. Implement only when requested; re-run the disproving gate.

Definition of done

A working solution is a chain of named evidence.

CollocatedAll versioned tooling remains inside the skill.
DeterministicThe same CLI applies the same checks every run.
Source-safeRead-only commands do not modify UiPath projects.
Contract-awareInvoke names, directions, types, and registrations are checked.
Runner-safeProduction execution needs explicit side-effect authorization.
TruthfulL1, L2, L3, and UAT remain distinct.
ReviewableBehavior-sensitive tests exist before superseded tests disappear.
PortableThe request/result protocol can support a future runner adapter.
